# Third-party notices

Foundry Lite is distributed with open-source Python packages. The authoritative component inventory for each Windows release is the generated CycloneDX SBOM (`foundry-lite-sbom.json`).

Notable runtime components include FastAPI, Uvicorn, HTTPX, Pydantic, SQLAlchemy, cryptography, argon2-cffi, JSON Schema, PyYAML, Pillow, and pystray. Their respective licenses remain in force. PyInstaller and Inno Setup are build and packaging tools and are not representations of endorsement.
